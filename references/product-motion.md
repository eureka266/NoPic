# /product-motion：产品营销动图 / Carrot 索引

本包以外部技能索引方式接入 `carrot`：提供统一入口、用途判断和中文使用指引，完整制作流程仍由已安装的 Carrot 维护。不把其 `SKILL.md` 单独复制为一个假定可用的内置动画模块。

## 用途判断

| 用户目标 | 入口 | 依据 |
| --- | --- | --- |
| 制作或修改静态品牌、合作、金句、概要配图 | 本包静态工作流 | 使用品牌模板与准确文字/Logo 素材 |
| 已有配图的背景网格循环 | `/animate-cover` | 同一 cover project 的 motion 呈现；使用 `partnership-grid-flow` 配方 |
| 展示产品功能、关键操作、状态变化或价值，用于官网/落地页/邮件 | `/product-motion` → `$carrot` | 从产品知识库与真实 UI 证据构建短篇 2D 动画 |
| 3D、长篇配音教程、以社交剪辑为主的视频 | 不自动进入 Carrot | 超出其当前定位；依据实际请求另选流程 |

两种动图入口按传播目标划分。不能仅看到“动图/GIF”就将合作海报路由到 Carrot，也不能将产品动图降为背景纹理运动。用户明确点名 Carrot 时优先读取它；若请求超出其范围，说明范围并提出与目标相符的执行方式。

## 读取并使用 Carrot

1. 优先使用当前会话提供的 `carrot` 技能位置或用户给出的路径，读取其完整 `SKILL.md`。文件型环境可检查 `<当前技能根目录>/carrot/SKILL.md`，常见安装位置为 `~/.codex/skills/carrot/SKILL.md`。引用文件、脚本和资产始终相对于 Carrot 自己的目录解析。不要写死某位用户的主目录作为跨机器依赖。
2. 不可用时明确说明缺少的是外部 Carrot 技能，不宣称它已经内置或可执行。可保留用户的产品目标并整理交接需求；未经用户要求不安装、不复制、不同步技能。本包指令不会创建另一个聊天或发送跨聊天消息。
3. 原样传递产品、功能、投放位置、传播目标、参考、已有脚本、素材路径与已给授权。不要求用户重新输入 `$carrot` 或重述已有需求；同一对话中按读取到的 Carrot 工作流继续。
4. 实际制作时执行 Carrot 的本地知识库优先、产品事实与素材检索、脚本和 UI 质量检查、生产与交付流程。涉及 HyperFrames 制作时按其要求进入 `hyperframes`。仅请求用法说明、索引维护或适用性分析时，不启动知识库生产流程、环境安装或动画渲染。
5. 按 Carrot 的当前规则处理必要的脚本、素材、访问与预览确认；已有授权和用户明确的自动推进要求必须保留。本索引不增加额外审批，也不以路由替代 Carrot 所需的事实核查与素材准备。

## 品牌与尺寸的衔接

- 本包 `/animate-cover` 默认保留确认配色，可选单蓝、单橙、蓝橙、黑白灰；默认 5 秒、源图尺寸等仅为配图动效的制作默认值，不作为 Carrot 的通用默认值。
- 用户指定 BlockSec 纯黑或蓝橙风格时，将要求传递给 Carrot，并用于营销画布、标题和装饰；真实产品 UI 的原生颜色、字体、布局、控件、风险等级和状态保持真实，不能为了配色而改写事实。
- 未指定品牌背景时，使用 Carrot 的投放场景规范。例如邮件可采用中性浅色画布；不能因本包强调深色而强制改成黑底。
- Carrot 新项目默认 1920×1080 Full HD；明确的其他比例、投放约束和已有项目尺寸优先。网站优先视频与 poster，邮件按需求交付 GIF 与 fallback；循环方式和时长由内容与阅读时间决定。
- Carrot 保存项目和索引的规则沿用其当前规范。本包不擅自将其产物改存为普通社交封面项目，也不自动提交或推送。

## 能否直接作为内置模块

Carrot 的能力与本包“内容营销配图”的范围互补，但当前依赖独立维护的完整目录：产品事实检索、UI 采集/复原、脚本框架、素材表、HyperFrames 脚手架、UI 与 GIF 验证器、字体/光标及其他资产；还引用本地产品知识库、PM Copilot 规则和相关制作技能。

因此本次采用 **外部索引**，避免复制后流程和资产不同步。它使用户在本包内有产品营销动图入口，但不构成独立部署的内置动画引擎。

若将来明确要求打成独立发行包，应另行确定 Carrot 的来源与版本、完整依赖边界、共享资产、知识库解析方式与安装位置，提供实际安装检查，再验证产品脚本、UI 动画、渲染与交付。不通过只拷贝一份 `SKILL.md` 宣称已完成整合。

中文调用示例见 [README](user-manual.md#产品营销动图)。
