# 使用手册

1. 在当前项目提供并安装已获授权的组织素材包，打开NoPic工作台。
2. 用自然语言给出用途、定稿文案、画幅及锁定范围，上传原件或选择包内正式资源。
3. 复用适用模板和已有底图；新底图需明确授权，默认参考请求先分析。
4. 核对真实预览与最终导出，保留独立背景和可编辑项目。
5. 后续修改提供项目目录，不只提供扁平成图。项目模板快照与素材优先于组织库的新版本。

没有包时工作台显示空态，上传和分析准备仍可用；缺少渲染输入时不假装成功。正式素材、具体模板和团队认可的方案在独立组织库维护，不提交进方法论仓库。

只要求审阅时使用 `nopic-design-quality`，输出具体问题与证据。截图不足以验证交互、响应式或全部功能。
