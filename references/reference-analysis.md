# 参考分析与组织共建

参考图只贡献经允许的结构规律，不能带入外部的品牌、人物、文案、客户关系或独特资产。

记录内容类型、视觉摘要、阅读顺序、颜色角色、字体类别与置信度、归一化几何、安全区、图层职责、背景提示词、复用条件及例外。字体无法从位图确认时写推断，不把猜测当事实。

仅分析时在当前项目交付；用户要求团队复用时，在独立组织素材仓库保存候选记录。每项使用稳定ID和版本，关联真实代表图、来源、选择理由、适用场景和验证结果。

状态区分候选、规格已审阅与已验证可复用。不能把未渲染的规格称为可直接用模板，不能把展示授权等同团队审美认可。模板、底图与样例仅在有明确确认与权限时发布组织包新版本。
