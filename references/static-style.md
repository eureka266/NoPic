# 静态母版检查与可选风格调整

静图和动图共用同一张已确认母版。`/animate-cover` 默认保留它的颜色、构图、文字与素材；先检查可读性、前景和动画源图层，不要求每次重做静态风格。用户明确要求换风格时，才进行本文件的可选 style-pass。新绘制背景仍遵守主技能的原生 image_gen 与授权边界。

## 风格选择

这些是设计意图标签，不是静图渲染器的命令行参数：

- `preserve`：默认，沿用项目现有配色与背景，不因启用动效重设计。
- `blocksec-black`：纯黑 / 近黑与黑白灰层次，呼应 BlockSec 黑色 Logo，可完全没有彩色装饰。
- `blocksec-blue`：蓝色及同色明暗可成为主色，配中性色，不强加橙色。
- `blocksec-orange`：橙色及同色明暗可成为主色，配中性色，不强加蓝色。
- `blocksec-blue-orange`：明确主色、次色与面积关系，不默认渐变或固定角落光晕。

单色、留白、几何、材质与渐变都是可选择的设计手段，不为体现品牌而堆叠颜色。深浅主题与上述方向分别选择。风格一次确定后，改文案或启用动态版本不会改变它；官方 Logo 始终保留原色与比例。详细原则以 [品牌规范](brand-and-templates.md) 为准。

## 母版与图层检查

1. 读取原 cover project，复用 `content.json`、背景和正式素材。已有项目可直接重编译；新渲染器会保存精确透明前景，避免从扁平 PNG 猜测文字和 Logo。
2. 动态配图的背景需有实际独立纹理层与固定底色，或可用的无字背景动画序列。无法分离时查找原始素材，不能把整张海报移动冒充背景运动。
3. 只有用户要求调整风格时才修改允许的背景 / 材质 / 装饰；新画或重绘必须使用原生 image_gen，程序只合成已有素材。普通“做成动图”本身不授权换底图。
4. 保留逐字文案、数字、日期、机构身份、合作关系、Logo 原色 / 比例 / 透明度、版式和画幅。扁平图无法保真提取时保留原图并说明限制，不用 AI 猜字或 Logo。
5. 检查静态母版及动画第一帧，确保同一视觉体系。单蓝 / 单橙方向不为“补齐品牌色”添加另一色，最小正文和 Logo 保持清晰。

## 仅在已要求换风格时使用的提示词

```text
在用户授权范围内，把现有配图的背景与装饰调整为 {用户选择的配色方向}。保留全部准确文字、数字、日期、机构与合作关系，保留官方 Logo 的身份、原色、比例、位置和清晰度，保持构图层级、画幅与安全区。

颜色服务于主题与信息层级；允许单蓝、单橙、黑白灰或主次明确的蓝橙组合，渐变和光晕不是必需元素。只改允许的背景 / 材质 / 装饰，不让图像模型重绘文字或官方 Logo。后续动态版本复用同一母版，不再换背景或风格。
```
