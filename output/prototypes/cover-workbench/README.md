# NoPic 本地工作台

从仓库根目录运行 `python3 scripts/start_workbench.py --project-root /path/to/project`，使用返回的本地URL。工作台在当前项目保存状态和原件，不内置任何组织的底图、模板或示例图。

无组织包时画布显示空态，上传、参考分析任务与会话交接仍可使用。先在当前项目安装组织包，再启动服务，界面会按manifest显示包内背景、模板与正式标识。

HTML、CSS与JavaScript是工作台源码。没有内嵌图片或单文件外观预览；实际合成由通用渲染器读取外部组织包完成。用户确认后才交付，浏览器本身不运行图像模型。

工作台只绑定本机地址，并限制同源请求、上传分类和文件路径。`.nopic/workspace/`、旧的本地workspace以及开发环境不提交。生产素材和参考图应存入组织素材仓库的新版本，不能回写方法论源码。
