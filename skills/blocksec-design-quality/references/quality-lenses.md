# 对象检查细则

按当前对象读取，局部任务只检查相关项。以下是检查问题，不是给任何界面或图片强行增加模块的要求。

## 工作型 UI

适用于工作台、控制台、调查视图、筛查结果、表单、设置、表格等。

### 任务和信息

- 说出用户在当前页面要完成的一个主要任务；主操作、上下文和结果的位置是否便于找到？
- 调查、筛查或监控页面里的对象、链、时间范围、方向、单位、筛选条件和数据来源，在影响判断时是否可见？不要求每页机械展示全部字段。
- 风险等级、评估时间、缺失数据和处理状态是否符合真实产品定义？未评估、处理中、无数据和低风险不能用同一种“绿色安全”状态表示。
- 屏幕上显示的是识别、分析、提醒还是执行结果？按钮和文案不能暗示产品具备未经确认的阻止或执行能力。
- 信息量较大时保留完成任务必需的密度，用分组、对齐和展开支持扫描，不为了留白隐藏关键内容。

### 表格、图表和状态

- 数字、金额、币种和精度可比较，长地址和哈希的截断不导致对象混淆；完整值在需要时可查看或复制。
- 图表类型服务实际问题，轴、单位、时间范围和图例清楚。避免仅因颜色好看给同一指标分配不同含义，或让品牌色覆盖风险语义。
- 区分真实数据和演示数据；不要补造指标、客户数或假成功状态填充版面。
- 表格关键列和主要操作在实际宽度下可用。确有必要的横向滚动可以接受，但要能发现和操作。
- 相关的加载、空态、错误、禁用、选择和成功状态可理解；颜色之外还有文字或形状提示。

### 交互、适配和可访问性

- 关键操作的名称、反馈、下一步清楚；相关筛选、切换、表单与返回路径在授权测试范围内有效。
- 前端实现可操作时检查键盘焦点、必要的标签与语义、相关对比度和触控使用；仅凭截图不能确认这些条件通过。
- 目标宽度下导航、表格、侧栏、弹窗和长内容不遮挡主任务。移动端有实际任务需求时检查移动路径，不机械要求全部桌面信息原样缩小。
- 沿用已有组件、tokens 和状态语义；发现不一致时先判断是否有功能理由。

## 营销网页

适用于官网、产品页、活动页与落地页。页面中的产品截图再按 UI 标准检查其可见内容。

- 首屏能说明面向谁、解决什么、主行动是什么；已有明确转化目标时保持行动层级。
- 模块顺序服务读者理解：问题、能力、机制、证据、下一步如何衔接？不强制固定模板顺序。
- 产品图、机制图和实例承担说明作用；抽象装饰不能替代需要解释的产品内容。
- 产品名、能力、数据和客户关系有来源。Logo 墙、证言、收益与安全保证不能为美化页面而编造。
- 标题、图片、色块与留白形成有意义的节奏；不同段落可有不同结构，但不为变化破坏理解。
- 主操作在实际视口下可见、可理解；链接与按钮的作用符合文案。只有静态图时不声称转化路径可用。
- 真实浏览器中检查字体、图片和目标断点；深浅主题只在任务或产品确实支持时检查。

## 内容营销配图

适用于社交封面、合作公告、产品更新、研究图、活动海报、嘉宾金句与 seminar 概要。

### 信息与构图

- 第一眼能识别主要主题或关系，第二眼获得必要补充；标题、Logo、人物和主视觉不同时争夺第一层级。
- 合作公告：双方可辨识、视觉重量平衡，不简单按素材文件宽度判定平衡；不暗示未经确认的背书或合作范围。
- 研究、安全事件：标题、机制、数据和来源之间关系正确。不要用泛化盾牌、锁或货币图标替代实际说明。
- 产品更新：优先表达变化或收益；真实产品截图不能被缩得无法辨认，也不能通过编辑虚构产品状态。
- 活动与人物：活动名称、时间地点、人物身份、原话归属在需要时清楚；不要擅改引文。
- 长中文标题优先在现有区域调整换行、层级和字号；不能擅自改写已锁定文案，也不机械套用英文短标题规则。仍溢出时提出缩文案或调整版式的具体选择。

### 画面与交付

- 在预计投放尺寸下检查最小文字、Logo、人物轮廓和阅读顺序。小尺寸预览用于发现问题，不按固定缩放比例代替真实场景。
- 背景和纹理支撑主题，文字区保持可读；允许渐变、网格、光感或纯色，只判断它们对本图的实际作用。
- Logo 保持正式形态、比例、清晰度和必要间距，背景适配正确；没有素材时不以普通字体或 AI 重画代替。
- 人物抠图无明显白边、缺损和不自然遮挡；如使用合成，尺寸和光感不造成明显割裂。
- 跨画幅时使用对应版式，不把整张成图强行裁切。比例、导出格式和文件内容符合这次要求。
- 检查最终导出文件，而不只看编辑预览；需要可编辑交付时保留项目、原素材引用及独立图层。

## 系列与跨页面检查

仅对用户提供的一组材料或明确要求覆盖的页面执行；不自动扩张到整个站点或生成额外作品。

1. **先分组**：品牌、产品、内容类型、语言、画幅与系列关系。合作公告与研究封面可以有不同重心，中文与英文也可以有不同字号与换行。
2. **共同锚点**：核对适用的 Logo 版本、字体层级、颜色角色、文本安全区、组件语义和素材处理。比较视觉重量与比例，不能只比较原始像素宽度。
3. **变化理由**：用主题、内容量、实际显示尺寸解释变化。没有理由的逐页漂移是问题；有理由的跨画幅适配不算不一致。
4. **UI 语义**：同一状态在不同页面的文字、颜色和图标含义一致；切换亮暗模式不改变风险定义。营销演示界面同样遵守产品真实语义。
5. **配图节奏**：系列能被识别，同时每张有自己的主要信息。标题层级、Logo 区和底图处理协调；不得为整齐而裁切文字或缩小到不可读。
6. **报告**：指出具体成员、共用依据与最小调整。只有截图时，跨页交互和真实响应式仍待验证。
